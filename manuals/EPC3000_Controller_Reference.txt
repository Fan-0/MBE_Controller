1. OVERVIEW & CONTROLLER CONCEPT
================================================================================
The EPC3000 is a range of programmable single-loop process controllers certified
for cybersecurity communications robustness. It supports PID, ON/OFF, valve
positioning, and ramp-dwell profile control. Applications include temperature,
carbon potential, dew point, and heat/cool control.

Quick Start Codes allow fast out-of-box commissioning without configuration
software. Full configuration is possible via:
  - Front panel HMI
  - Eurotherm iTools software (free download: www.eurotherm.com)
  - Digital communications (Modbus RTU, EI-Bisynch, Ethernet)

Supplements for specific applications:
  - HA033033: Temperature Control Applications
  - HA032987: Carbon Potential Control
  - HA032994: Dew Point Control

3. SAFETY & EMC NOTES
================================================================================
- Install, operate, and maintain only with qualified personnel.
- Power down ALL equipment before installation, wiring, or inspection.
- Primary Sensor Input (IP1) is NOT isolated from logic outputs or DI1/DI2.
  Terminals may be at line potential if sensor is at line voltage.
- CT input and Digital Inputs are NOT isolated from Primary Sensor Input.
- Use copper cables except for thermocouple wiring.
- Route low-voltage DC and sensor wiring away from high-current power cables.
  Use shielded cable if unavoidable; ground shield at one end only.
- External fusing required. Recommended: T-rated 2A 250V.
- For permanently connected equipment, include an isolating switch or breaker.
- Do not disassemble, repair, or modify the equipment.
- Conductive pollution must be excluded from the cabinet.
- DANGER: Controller entering Configuration Mode PAUSES all outputs.

================================================================================
4. CYBERSECURITY
================================================================================
- Achilles Level 1 Communications Robustness Certification.
- All comms ports DISABLED by default; must be explicitly enabled.
- Exception: USB config clip port (physically inaccessible when installed).
- Bonjour/ZeroConf auto-discovery OFF by default.
- HMI password entry is obscured; locked after 3 invalid attempts.
- iTools comms config password: min 8 chars, locked after 5 failed attempts,
  salted+hashed storage, encrypted transmission.
- Comms Lockdown mode limits access until password is set.
- Ethernet rate protection and broadcast storm protection built-in.
- Comms watchdog configurable (W.TIME, W.ACTN, W.RCOV, W.FLAG parameters).
- Flash and non-volatile memory integrity checked at power-up and periodically.
- Clone files include cryptographic integrity hash; tampered files will not load.
- Decommission: revert to defaults via Cold Start before disposal.

Active Ports (only opened when corresponding protocol is enabled):
  - 44818 TCP/UDP: EtherNetIP
  - 2222/22112 UDP: EtherNetIP
  - 502 TCP: Modbus Master and Slave
  - 47808 UDP: BACnet
  - 5353 UDP: ZeroConf/Bonjour (when AutoDiscovery = ON)

5. INSTALLATION & WIRING
================================================================================
Panel cutout dimensions per model:
  - EPC3016: 45mm x 45mm
  - EPC3008: 45mm x 92mm
  - EPC3004: 92mm x 92mm

Key wiring notes:
  - Max two wires per terminal (same type and cross-section).
  - Strip insulation minimum 6mm; max exposed conductor 2mm.
  - Tighten terminals per torque specifications.
  - CT installations: fit voltage-limiting device (back-to-back zener diodes,
    3–10V, 50mA) across CT terminals to prevent high voltage if disconnected.
  - Isolation: 300Vac CAT II double isolation for most IO, relays, and comms.
  - Primary sensor input and logic/digital IOs share common ground (NOT isolated).
  - Transmitter power supply (EPC3008/3004 only): 24Vdc ±10%, 28mA max.

EPC3008/EPC3004 Terminal Layout (rear):
  - NO / C / NC: Output 3 (OP3) changeover relay
  - 24V transmitter supply
  - 4A / 4B: IO4
  - DI1 / DI2 / C: Digital contact inputs
  - CT / C / LA / LB: Current transformer and digital inputs
  - COM / A / B: EIA-485 RS-485 digital communications
  - IP2: Secondary sensor input (option)
  - IP1: Primary sensor input
  - 1A/1B, 2A/2B, 3A/3B/3C: IO1, IO2, OP3
  - 5A/5B: Transmitter 24V supply
  - Line / Neutral: Power supply

6. INPUTS & OUTPUTS (IO)
================================================================================
IO1 and IO2: Standard on all models. Configurable as:
  - Form A Relay Output (2A 230Vac, isolated 300Vac)
  - Logic/SSR Drive Output (12Vdc @ 44mA max, NOT isolated from sensor)
  - Triac Output (40mA–0.75A rms, 30–230Vac, isolated 300Vac)
  - Analog Output (0–10Vdc, 0–20mA, or 4–20mA, isolated 300Vac)
  - Contact Input (12Vdc @ 40mA, NOT isolated from sensor)

IO3 (OP3): Standard changeover relay (Form C) — all models.
  - 2A 230Vac, isolated 300Vac

IO4: Standard on EPC3008 and EPC3004 only. Same options as IO1/IO2.

Primary Sensor Input (IP1): All models. Accepts:
  - Thermocouple (various types)
  - RTD (Pt100, Pt1000, 2-wire or 3-wire)
  - Linear: mA, mV, 1V, 10V (add 2.49Ω burden resistor for mA input)

Secondary Sensor Input (IP2): Option on EPC3008/EPC3004 only.
  - Same input types as IP1.

Current Transformer (CT): Standard on EPC3008/EPC3004; option on EPC3016.
  - Range: 0–50mA rms sine wave, calibrated 50/60Hz.
  - Resolution: 0.1A (≤10A scale), 1A (≤100A scale), 10A (≤1000A scale).
  - Accuracy: ±1% of reading.
  - Internal burden resistor: 10Ω.

Digital Inputs DI1/DI2 (LA/LB/LC):
  - EPC3008/3004: two contact closure inputs.
  - Switching: 12Vdc @ 13mA max; closed <100Ω, open >400Ω.

Digital IO D1–D8 (Option):
  - Voltage input: High ≥4V (max 35V), Low ≤-1V to 1V.
  - Contact: closed 0–100Ω, open >28kΩ.
  - Output: current sinking, external 15–35Vdc PSU.

Analog Output calibration accuracy:
  - Voltage: ±0.5% + 50mV offset
  - Current: ±0.5% + 100µA offset

7. OPERATOR INTERFACE
================================================================================
Operator Levels:
  Level 1 — Default power-up; no password required; routine operation.
  Level 2 — Supervisor; extended operational parameters; password required.
  Level 3 — Commissioning; configuration parameters; password required.

--- PAGE 60 (VERBATIM) ---

Digital Communications Connections

In the EPC3008 controller and the EPC3004 controller, EIA-485 RS-485 is
standard. EIA-232 RS-232 and EIA-422 RS-422 are not supported.

In the EPC3016 controller, EIA-485 RS-485, EIA-422 RS-422 and EIA-232 RS-232
are supported via the option board.

Modbus RTU or EI-Bisynch protocol is used for compatibility with existing
controllers.

Ethernet Modbus TCP is also supplied as an option in all controllers. When
connecting a computer to EIA-232 a USB adaptor is typically used. It is good
practice to use electrically isolated adaptors, since electrical noise from an
industrial situation may otherwise be transmitted to the computer damaging it.

To help prevent earth ground loops, the cable shield should be grounded at one
point only.

Isolated 300Vac CAT II. Note: In the following wiring diagrams, the terminal
functions are correct, but the terminal layout may not be in the same order as
on the instrument.

EIA-232 Wiring

EIA-232 is available in EPC3016 controller only and is used to connect one
master and one slave.

  EPC3016 Terminals: HD (Common), HE (Rx), HF (Tx)
  Connection: Twisted pair, shielding grounded at one end
  Typical connection via EIA-232 to USB converter: Tx, Com, Rx → USB

--- PAGE 61 (VERBATIM) ---

Serial Communications EIA-485

The EIA-485 Modbus RTU function of an EPC3016, EPC3008, EPC3004 controller
provides an alternative digital communications method to Ethernet. It is
independent of Ethernet and can be used at the same time that Ethernet
communications are active. Data transmission is slower than Ethernet, but it
is an effective communications method in some situations.

It may be used in the following example contexts:
1. Connection to legacy EIA-485 Automation networks for SCADA or data
   acquisition.
2. Direct connection to Programmable Logic Controllers using a serial network.
3. To interconnect an EPC3016, EPC3008, EPC3004 controller, for example to use
   the broadcast master function to send a digital master setpoint profile to
   downstream slave devices.
4. To connect Eurotherm iTools, typically in situations where older types of
   instruments such as Series 3000 controllers are being replaced and EIA-485
   infrastructure is already present. Ethernet will always be a better
   connection method for new installations.

When connecting a computer to EIA-485, a USB adaptor is typically used. It is
good practice to use electrically isolated adaptors, since electrical noise from
an industrial situation may otherwise be transmitted to the computer damaging it.

EIA-485 supports up to 32 devices per network segment. Segment repeaters may
be used to increase the number of devices in an EIA-485 network. Note that
220Ω termination resistors are required at the start and end of the RS485 line.
Without these, communications will suffer intermittent faults.

Connections using a suitable converter are shown in the following diagram.

  EPC3000 Controller Terminals: HD (Common), HE (Rx/B), HF (Tx/A)
  Connection: Twisted pair, shielding grounded at one end
  USB-to-EIA-485 converter: Tx, Com, Rx → USB
  220Ω termination resistors required at BOTH ends of the RS-485 line.
  Topology: Daisy chain to further controllers or PLCs.

9. DIGITAL COMMUNICATIONS — RS-422, ETHERNET, PROTOCOLS
================================================================================

EIA-422 (RS-422) — EPC3016 Option Only:
  - Up to 31 slaves; separate Tx and Rx twisted pairs (4-wire).
  - Terminals: HA/HB (Rx-/Rx+), HC (Com), HD/HE (NC/Tx-), HF (Tx+)
  - 220Ω termination on last Rx of converter and last Rx instrument in line.
  - Daisy chain topology.

Ethernet:
  - RJ45 connector on option board.
  - LED indicators: Green = network speed (ON=100Mbps, Off=10Mbps);
    Flashing Amber = network activity.
  - 10/100BASE-T, auto-sensing.

Supported Ethernet Protocols (from firmware V4.01+):
  - m.sLV  — Modbus TCP Slave only
  - EIP.m  — EtherNetIP Adapter + Modbus TCP Slave
  - bAC.m  — BACnet + Modbus TCP Slave
  - m.mst  — Modbus TCP Master + Slave

Serial Protocols:
  - m.Rtu  — Modbus RTU Slave (and Master from V4.01+, chargeable option)
  - EI.bS  — EI-Bisynch Slave

EI-Bisynch:
  - Proprietary Eurotherm protocol; based on ANSI X3.28-2.5 A4.
  - ASCII-based asynchronous; 7 data bits, even parity, 1 stop bit.
  - Reference: Series Communications Handbook HA026230 (www.eurotherm.com)

Modbus RTU:
  - Single master, one or more slaves (multi-drop).
  - Uses CRC (Cyclic Redundancy Check).
  - JBUS identical except 1-based register addressing vs. Modbus 0-based.
  - Full Modbus address list available in iTools Browser List.

Communications Parameters (HMI Path: COMM LIST → F.COM or O.COM → mAIN/nWrk):
  INTF  — Interface type (r485, r232, r422, ETH)
  PROT  — Protocol (nonE, m.sLV, EI.bS, m.mST, m.tcp, EIP.m, bAC.m)
  BAUD  — Baud rate (4800, 9600 default EI-Bisynch; 19200 default Modbus RTU)
  PRTY  — Parity (NONE, EVEN, Odd)
  NODE  — Node address (1–254; default 1; 255 reserved for config port)
  DELAY — TX delay after RX (Yes/No)
  T.FMT — Time format (mSEC, SEC, mIN, HOuR)
  W.TIME — Comms watchdog timeout (0 = disabled)
  W.ACTN — Watchdog action (mAN = manual clear; Auto = auto clear)
  W.RCOV — Watchdog recovery delay
  W.FLAG — Watchdog flag status

Ethernet Network Parameters (HMI Path: COMM LIST → O.COM → nWrk):
  IP.MD — IP mode (StAt = static, dHCP = DHCP)
  IP.A1–A4 — IP Address bytes (default 192.168.111.222)
  IP.S1–S4 — Subnet mask (default 255.255.255.0)
  IP.G1–G4 — Default gateway (default 0.0.0.0)
  MAC1–MAC6 — MAC address (read-only)
  A.DISC — Auto-discovery (OFF default; On = enable Bonjour)
  B.STM  — Broadcast storm protection status
  R.PRT  — Rate protection status

SCADA Modbus Address Table:
  - Fixed parameters at addresses 0x0000 to 0x3CFF (0–15615 decimal)
  - Comms Indirection Table (CommTab): addresses 0x3C00–0x3CFF (15360–15615)

Modbus Master (V4.01+, feature security required):
  - Up to 3 Modbus slave devices (TCP, RTU, or mixed).
  - Up to 32 data points shared across all slaves.
  - Configurable timeouts and retries per slave.
  - Supported profiles: EPC3000, EPC2000, ePack, 3200, ePower.
  - Access via iTools or HMI.

10. CONTROL LOOP & PID
================================================================================
- 2 PID sets standard; up to 8 with optional extension.
- Separate proportional bands for heat and cool channels.
- Enhanced autotuning with cutback to minimize overshoot.
- Valve Positioning (VPU): unbounded algorithm, no slidewire required.
- Gain scheduling: up to 8 sets, selectable by deviation, absolute value,
  output level, or other criteria.
- Feedforward: disturbance, setpoint, and power (line voltage) compensation.
- Split range heat/cool; non-linear cooling; deadband.
- Bumpless transfer; sensor break handling.
- Output subsystem: Manual Station, rate limiting, position limiting.
- Output limits sources: master limits, gain-scheduled limits, remote limits, tune limits.

Modes:
  AUTO   — PID control to setpoint
  MANUAL — Operator-set output demand
  HOLD   — Previous working output held
  TRACK  — Output follows TrackOP input

Setpoint Sources:
  - Local (SP1, SP2 selectable)
  - Remote (analog input)
  - Programmer (ramp-dwell profile)
  - Digital communications

11. SETPOINT PROGRAMMING (RAMP-DWELL)
================================================================================
Options: 20x8, 10x24, 1x24, or 1x8 profiles.

Segment Types:
  - RAMP (by rate or time to target)
  - DWELL (soak at setpoint)
  - STEP (instant jump to target)
  - CALL (subroutine; call program number must be > current program number)

Segment Parameters:
  - TSP: Target setpoint
  - R.RATE / R.TIME: Ramp rate or ramp time
  - DUR: Dwell duration
  - EV.OP: Event outputs (bitmask, decimal; e.g., 6 = events 2 and 3)
  - C.PRG.N: Called program number (for CALL segments)

Holdback (Guaranteed Soak):
  - Holds programmer if PV deviates from setpoint beyond holdback band.

12. ALARMS
================================================================================
Up to 6 alarms, each configurable as:
  Abs.H (1)  — Absolute high
  Abs.L (2)  — Absolute low
  DeV.H (3)  — Deviation high
  DeV.L (4)  — Deviation low
  DeV.B (5)  — Deviation band
  R.ROC (6)  — Rising rate of change
  F.ROC (7)  — Falling rate of change
  Dig.H (8)  — Digital high (Boolean 1)
  Dig.L (9)  — Digital low (Boolean 0)

Latching types: None, Auto, Manual, Event (trigger only)
Alarm status: Off, Active, Inactive-Not-Acked, Active-Not-Acked
Alarm features: hysteresis, blocking, delay (0–9999.9s), inhibit, inhibit-in-standby.
Rate-of-change alarms have configurable rate, rate units (sec/min/hr), and filter time.

14. CALIBRATION
================================================================================
Analog Input Calibration (2-point):
  1. Enter Level 3 or Config mode.
  2. Allow 10 min warm-up.
  3. Connect mV source (with correct CJC for TC, or correct compensating cable).
  4. HMI: Instrument List → CAL → select input → Mode: Start → Lo → SetLo → Hi → SetHi.
  5. Status changes to "Adjusted" on success; "Factory" shows factory cal.
  6. To discard user cal: select "Disc" in Mode parameter.

Analog Output Calibration (2-point, example OP2):
  1. Connect voltmeter or ammeter to output terminals (e.g., 2A/2B for OP2).
  2. HMI: Level 3 → Instrument List → CAL → select dC.1/2/3.
  3. Mode: Start → Lo → enter meter reading into C.VAL → SetLo → Hi →
     enter meter reading into C.VAL → SetHi.
  4. Voltage Low point = 2.00V; High point = 10.00V.
  5. Current Low point = 4.00mA; High point = 20.00mA.

CT Calibration (2-point, DC current source):
  1. Connect DC current source: +ve → C terminal, -ve → CT terminal.
  2. Set ID = CT in Instrument Cal list.
  3. Mode → Low → inject current (e.g., 35mA) → enter 35.00 in CalValue → SetLow.
  4. Mode → High → inject current (e.g., 70mA) → enter 70.00 in CalValue → SetHigh.
  5. Mode shows "Adjusted" on success.

Two-point offset calibration available via controller HMI or dry block calibrator.
Factory calibration can be restored at any time.
